# ADR-0010：桌面布局持久化与终端会话恢复

- 状态：**Accepted（V1.2 规划决策，尚未实施）**
- 日期：2026-10-18
- 关联：[SPEC-0006 桌面工作区](../spec/0006-desktop-workspace.md)、[ADR-0005 终端架构](0005-terminal-architecture.md)、[ADR-0008 认证与设置](0008-authentication-and-settings.md)

## 背景

桌面模式要求刷新浏览器后恢复图标、Dock、窗口和应用上下文。EdgeDesk 的终端是服务端真实 Bash/PT​​Y 会话，独立于浏览器页面和 WebSocket；桌面窗口状态不能被误认为后端会话状态。文件编辑器还必须避免将敏感文件正文默认写入浏览器本地存储。

## 决策

### 1. 桌面 UI 状态保存在浏览器本地

- 使用 localStorage 存储版本化布局文档，不增加后端接口、数据库或同步服务。
- 使用独立 key 和 schemaVersion；所有读取、校验、写入、回退集中在 DesktopPersistence 模块。
- 持久化桌面图标位置、Dock 固定应用、窗口应用 ID/实例标识、几何状态、最大化/最小化状态和可用于重连的会话引用。
- 不持久化密码、Cookie、API Token、文件正文或其他认证凭据。
- 主题等现有跨浏览器偏好仍由现有 settings API 管理，不复制进桌面布局。

### 2. 恢复是重新构建 UI，不是恢复进程

恢复必须在认证完成后进行，并按顺序校验布局、应用注册、文件路径和真实终端会话。浏览器本地状态只提供恢复提示，不提供授权。服务端现有认证、授权、会话归属校验和资源限制始终是最终依据。

- 有效的 Bash session ID：重新连接现有会话，保留原有会话输出重放和尺寸同步机制。
- 无效或已结束的 session ID：显示会话已结束/不可恢复，不自动创建新的 Bash 替代它。
- 服务进程重启导致会话消失时，允许桌面窗口恢复，但必须显示真实失效状态。
- 文件路径恢复时重新请求服务端验证；路径不存在或无权访问时显示错误，不跳转到其他路径。
- 编辑器恢复时重新读取磁盘文件；V1.2 不保存本地正文草稿。文件在外部发生变化时必须避免静默覆盖。

### 3. 终端窗口和会话生命周期分离

- WebSocket 断连、浏览器刷新、最小化或关闭终端窗口，不应单独触发后端 Bash 终止。
- 关闭终端窗口只关闭 UI/订阅；显式结束会话仍使用现有终端操作。
- 终端标签页的显式关闭行为继续遵守 SPEC-0003 的现有契约；桌面窗口关闭不得被误当成关闭其中某个会话标签。
- 重连前先确认会话存在且服务端认证/归属校验通过。不得仅凭本地保存的 session ID 授予访问权限。

### 4. 故障和迁移策略

- localStorage 不可用、写入失败、数据损坏、版本不支持或数据超限时，使用默认布局启动，不阻断登录。
- 对每个窗口单独验证；一条坏记录不能导致整份布局恢复失败。
- 无效 appId、重复单实例应用、超出视口的坐标和非法尺寸必须安全修正或丢弃。
- 版本升级时明确迁移；无法迁移时清理无效布局并使用默认值，不删除服务端设置或认证文件。
- 退出登录时清除内存中的窗口和会话引用；非敏感布局可保留在本地，但再次登录后必须重新验证会话有效性。

## 备选方案

1. 服务端保存布局：需要新的持久化模型和接口，也会引入跨浏览器共享、用户身份和版本冲突等问题；当前单管理员、单浏览器桌面需求不需要该复杂度。
2. sessionStorage：无法满足关闭标签页/浏览器后重新打开仍尝试恢复桌面的需求。
3. 保存编辑器正文草稿：会在浏览器存储中留下敏感配置内容，且增加与外部修改的冲突处理；V1.2 不采用。

## 安全与隐私

- localStorage 内容可被同源 JavaScript 读取，故只允许存储非凭据的布局数据和会话引用。
- 不将布局中的路径或 session ID 当作授权证明；所有访问仍经过服务端现有保护。
- 不记录文件内容、密码、Cookie 或 API Token；测试应覆盖敏感字段未进入序列化结果。

## 验收

- 刷新后恢复完整工作区；改变视口后窗口位置尺寸被约束到可见区域。
- 仍存在的终端会话自动重连；不存在的会话显示明确状态，不创建替代会话。
- localStorage 损坏、不可用、版本不兼容时应用仍能进入默认桌面。
- 文件路径重新验证，编辑器不自动持久化文件正文，外部修改不会被静默覆盖。
- 单个窗口恢复失败不影响其他窗口，恢复流程不能绕过认证或授权。
