# SPEC-0001：产品定位与 V1.0 范围

- 状态：**Baseline（V1.0 基线记录）**
- V1.1 增量：管理员认证、首次初始化与系统设置见 [SPEC-0005](0005-authentication-and-settings.md)。
- 日期：2026-10-16
- 需求版本：V0.5（对话中已确认的最新条目）

## 定位

EdgeDesk：面向嵌入式／边缘 Linux 的单二进制、轻量、Web 化设备运维工作台。浏览器即可管理设备文件、使用真正的 Bash 终端，并查看设备实时资源占用；设备端不安装额外的 Java/Node/Python 运行时。

目标场景：工控板、采集网关、通信设备、无图形界面的 Linux 设备，以及需要提供安全现场排障入口的设备厂商。

## 原始功能清单中待排期的增强项

- 文件管理：多选 ZIP 下载、搜索、压缩与解压（原规划为 P2/P3）。
- 终端：只读观察模式、多标签快捷操作、会话数/超时策略细化。
- 前端：移动端适配、深浅主题。
- 部署：磁盘静态资源与 `#embed` 内嵌资源双模式；静态链接和多架构发行。
- 工程质量：分层、路径安全测试、静态检查、各平台构建和真实设备验收。

> 原始讨论中的“✅ 现有”描述的是**来源项目的功能状态**，并非 EdgeDesk 当前仓库已有实现。此仓库建仓时为空；完成情况必须由后续代码和测试证明。

## 不做什么

- 非通用云盘：不做公开分享、多人在线协作和版本历史。
- 非完整 SSH/SFTP 替代品：不做端口转发、SFTP 协议兼容和 SSH 密钥管理。
- 非应用部署平台：不做容器编排、CI、进程部署编排。
- V1.0 不建设云端设备管理控制平面。

## 验收准则

1. 在目标兼容设备上启动 Web 服务并完成受保护的文件操作。
2. 交互式 Bash 终端具备适用的登录环境，多 Tab 切换/页面导航/刷新不中断后端会话。
3. 文件管理页面可以并存、移动、缩放多个终端/编辑器窗口。
4. 仪表盘展示基本资源指标和持续更新的短时曲线，不要求数据库。
5. 多架构构建与静态链接的实际兼容性通过单独验证，不以文档目标代替测试结果。
