# SPEC-0002：文件管理

- 状态：**Baseline（已确认能力 + 待设计细节）**
- 日期：2026-10-16
- 前置文档：[产品范围](0001-product-scope.md)

## P0 功能

| 功能 | 行为和约束 |
| --- | --- |
| 目录浏览 | 按目录列出文件及文件夹，展示名称、类型、大小、修改时间、权限、属主/属组；支持隐藏文件、排序、分页 |
| 文件下载 | 流式响应，支持大文件和 HTTP Range 续传；不得整文件读入内存 |
| 文件上传 | 流式写入临时文件，成功后原子替换（同一文件系统内）；限制大小和可用磁盘空间 |
| 文本查看/编辑 | 仅面向 UTF-8 文本；控制编辑文件大小；保存时尽量保留原权限并采用原子替换 |
| 新建目录 | 提供 mkdir 操作 |
| 重命名 | 提供 rename 操作；正确处理跨文件系统失败 |
| 删除 | 支持单项与批量删除，目录递归删除应有明确确认及范围限制 |
| 路径范围 | 所有文件操作受配置文件根目录约束，防止路径穿越、符号链接逃逸及目录切换竞态 |

原始 API 草案：`POST /file/mkdir`、`POST /file/rename`、`POST /file/delete`。V1.0 实际端点见 [API 文档](../api.md)。

## 文件管理工作区

- 左侧为按需加载的目录树：从沙箱根 `/` 开始，展开时才请求该目录的直接子目录
  （`dirs_only=1`），不递归扫描整棵文件系统，也不跟随符号链接。
- 右侧为面包屑 + 工具栏 + 文件区；当前目录在树、面包屑和列表之间保持一致。
- 文件区支持列表视图与网格视图：列表支持名称/大小/修改时间排序并保留权限与 uid/gid 列；
  两种视图共享同一份文件数据与选择状态，切换视图不清空选择。
- 文件名筛选只作用于当前目录的当前页；跨目录搜索没有后端支持时不做虚假支持。
- 可在当前目录打开 Bash 终端，初始工作目录为该目录（受权限约束）。
- 可从文件列表打开在线文本编辑器，作为浮动窗口使用。
- 支持多个终端/编辑器窗口并存，窗口可拖拽、可缩放；见 [SPEC-0003](0003-terminal-workspace.md)。
- 从文件管理页面关闭或隐藏窗口时，不应凭空终止其他 Tab/页面正在使用的后端 Bash 会话。

## 建议的实现/安全约束

1. 安全路径处理封装在统一文件服务中，不在路由中各自拼接绝对路径。
2. 仅检查 `realpath` 后再打开不足以规避 TOCTOU；推荐安全目录 FD 操作及适当的 `openat2` / `openat` 降级方案。
3. 写入需要可写目录；只读根文件系统应允许只读浏览，并对不允许的写操作返回明确错误。
4. 路由层统一认证、授权、请求体积限制与错误映射。
5. 下载/上传中断、磁盘写满、权限不足、跨文件系统重命名等异常必须处理。
6. 默认上传权限方案原提案为 `0644`；新文件权限还需考虑 umask 和权限策略，最终数值待产品确认。

## 后续版本（原规划）

- P2：多选后 ZIP 打包下载、递归文件搜索。
- P3：tar.gz / zip 压缩和解压（须防范压缩包路径穿越和资源耗尽）。

## 验收

- 大文件操作为有界内存流式处理。
- 越权路径、符号链接逃逸和并发文件路径变化测试不能突破配置根目录。
- 权限错误、磁盘空间不足及中断时不留下被误认为成功的损坏文件。
- 在文件管理页可以同时打开多编辑器/终端浮动窗口。
