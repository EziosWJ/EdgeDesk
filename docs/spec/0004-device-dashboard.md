# SPEC-0004：设备仪表盘（硬件/系统资源）

- 状态：**Baseline（核心指标已确认）**
- 日期：2026-10-16
- 关联：[产品范围](0001-product-scope.md)

## 已确认功能

| 指标 | 当前值 | 短时间实时曲线 |
| --- | --- | --- |
| CPU 使用情况 | 必须 | 必须 |
| 内存使用情况 | 必须 | 必须 |
| 磁盘使用情况 | 必须 | 基础实时趋势；具体维度待设计 |
| 网络使用情况 | 必须 | 必须 |

- 展示实时基础指标和短时间趋势，不要求持久化跨重启历史。
- V1.0 不引入数据库和 ORM。
- 运行时间、系统版本、CPU 架构以及可用时的设备温度是**建议项**，尚未单独确认。

## 推荐采集与传输方案（非最终实现决策）

- 由 C++ 服务读取 Linux `/proc`、`/sys`、`statvfs` 等基础数据，不依赖外部 `top`、`free` 命令或数据库。
- 服务器使用可配置采样周期与内存环形缓冲，控制内存占用；浏览器通过 libhv HTTP API 定期获取数据。
- 网络吞吐、CPU 使用率由连续采样计算；第一帧可能没有速率数据。
- 支持硬件/驱动缺失某些指标时显示“不可用”，禁止虚构为 0。
- 不能因仪表盘持续采集而明显影响受限设备的正常业务。

## 待确认细节（2026-10-16 定案，见 ADR-0006）

1. 默认刷新频率：1000 ms（`--metrics-interval`）。
2. 曲线时间窗：默认最近 300 个样本（约 5 分钟，`--metrics-history`）。
3. 磁盘：默认按 `/proc/mounts` 中的真实块设备挂载点统计容量，不做磁盘 I/O 曲线；容量低频刷新（每 10 个周期）。
4. 网络：按每个网卡分别显示 RX/TX 速率，排除 `lo`。
5. 扩展指标：V1.0 提供 uptime、hostname、内核版本与 CPU 架构；不提供温度传感器。

## 验收

- 在受支持 Linux 设备上正确显示 CPU、内存、磁盘、网络的当前数据。
- 相关数值持续刷新，图表仅保存有限时间的数据。
- 缺少可选内核接口时不使 Web 服务崩溃。
- 程序和页面重启后无需读取历史数据库即可继续工作。
