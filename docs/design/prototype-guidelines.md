# EdgeDesk 原型拆解与 UI 实现规范

- 状态：**视觉参考**，不是已实现代码，也不等于产品已决定新增功能。
- 源：2026-10-16 生成的 4 张暗色 EdgeDesk 产品原型。
- 原型中的主机名、IP、时间、用量、数据库示例和活动记录全部是**虚构展示数据**。

## 页面与组件映射

| 原型页 | 核心 UI | 复用素材 | 必须实现为真实组件 |
| --- | --- | --- | --- |
| ① 仪表盘 | 设备资源总览 | `edge-device.svg`、`monitor-unavailable.svg` | 指标卡、折线图、环形图、自动刷新、采集失败提示 |
| ② 文件管理 | 目录树 + 面包屑 + 文件表格 + 多浮窗 | `empty-files.svg` | 上传下载、文件表格、浮动终端、浮动编辑器、拖拽与缩放 |
| ③ 终端工作区 | 多标签 Bash 终端 + 会话列表 | `empty-terminal.svg`、`session-disconnected.svg` | PTY/WebSocket 终端、Tab 切换、导航/刷新后会话恢复 |
| ④ 会话/设置 | 会话状态列表和系统配置 | 品牌与面板素材 | 会话列表、只读状态、受保护的配置表单 |

界面图标统一由组件提供：通用 UI/操作图标使用 `lucide-react`（ISC），文件类型图标使用
`@iconify-json/vscode-icons`（MIT，通过 `unplugin-icons` 构建期按需编译）。目录与符号链接
使用通用图标，普通文件按扩展名/特殊文件名显示对应格式图标。决策见
[ADR-0007](../adr/0007-frontend-icon-library.md)。

## 特别注意

1. 文件管理的浮动终端、编辑器支持多实例并存、拖动、缩放，界面窗口关闭动作与后台 Bash 会话销毁策略应分开处理。
2. 终端页面导航、Tab 切换和刷新**不得断开后台 Bash/PT​​Y 会话**，恢复方案以 SPEC-0003 为准。
3. 仪表盘只要求 CPU / 内存 / 磁盘 / 网络基础指标、当前值与短时曲线；不要因为原型图出现“最近活动”“时区”“账户管理”等元素就将其当作 V1.0 已确认需求。
4. 第四张原型中“SSH 密钥认证”“多用户登录”“命令审计”等属于**视觉展示项**，尚未被正式产品决策批准，不得由 Agent 擅自实现。
5. 终端窗口和编辑器使用真实组件，不拼接 PNG 截图；Bash 须正确加载适用的 profile 环境。
6. React 目前只是候选方案；设计资源可与原生前端或 React 共用。
7. 原型是视觉稿，具体布局应基于桌面宽度响应式改造，避免图片级像素还原损害操作易用性。

## Agent 交付要求

- 优先阅读 `docs/spec/*` 与 `docs/adr/*`，再参考本视觉规范。
- 优先使用 `web/public/assets` 中现成素材；缺失时以 SVG / CSS 或成熟图标组件补充，禁止截取包含文字/表格的界面图作为功能元素。
- 每一页提供空数据、加载中、失败、已连接/断开等状态；真实错误不伪装成功。
- 保持字体、间距、焦点可达性、键盘操作和窄屏溢出的合理行为。
- **原型还原度是验收项，不是可选项**：每个原型页必须在
  `docs/design/prototype-conformance.md` 维护逐项对照表；业务功能可用 ≠ 页面验收通过。
- 对照表中“待目视核对”的条目必须由人工在浏览器中确认后才能改为通过；
  不得凭代码自述直接宣称视觉还原完成。
- 所有指标、状态和数值必须来自真实 API/WebSocket；原型图中的演示数值一律不得进入代码。
