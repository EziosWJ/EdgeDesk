DESKTOP WORKSPACE / DESIGN KIT

桌面工作区与设备监控组件

独立页面原型与可复用 SVG 素材。桌面采用山湖壁纸、轻玻璃窗口与底部 Dock；设备概览借鉴 NAS 管理界面的资源卡片、趋势图和服务状态组织方式。
