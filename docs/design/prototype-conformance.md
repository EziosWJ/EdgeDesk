# 原型还原度对照表（验收清单）

- 状态：**验收基线**。业务功能可用 ≠ 页面验收通过；本表用于逐项核对，未列入“已实现”或未说明理由的条目不允许跳过。
- 视觉基准：`docs/design/prototype-guidelines.md` 所述的 4 张 EdgeDesk 原型图（本表当前覆盖 **① 仪表盘、② 文件管理**）。
- 数据原则：所有数值来自真实 API/WebSocket 采样；`null`/缺失显示“—”或“不可用”徽标，**不显示为 0，不虚构演示数值**（原型图中的 32%、12.4 MB/s、edge-001 等均为虚构展示数据）。

## 人工核对步骤（目视验收）

1. `cmake --build --preset dev-disk` 后运行二进制，浏览器打开对应端口并登录。
2. 打开“设备概览”，与原型截图逐列对照本表第 1–5 节。
3. 检查项：KPI 六卡内容与层次、三个图表面板的网格/坐标/图例/下拉、磁盘环形图与图例、设备状态徽标与列表、间距与配色。
